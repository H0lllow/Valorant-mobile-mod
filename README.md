# Valorant Mobile Mod

Chinese version (腾讯先锋) mod menu — aimbot, wallhack/ESP.

## Structure

| Folder | Purpose |
|---|---|
| `apk/` | Original and decompiled APK |
| `research/` | Memory dumps, offsets, structs |
| `mod/` | Smali patches, modified libs, overlay app |
| `tools/` | apktool, signapk, frida-server |
| `scripts/` | Build/decompile scripts |
